# ShapeFree Sorter: คู่มือใช้งานฉบับย่อ

ระบบใช้กล้องถ่ายบล็อกกับกระดานที่มีช่อง แล้วจับคู่ว่าบล็อกชิ้นไหนลงช่องไหนและต้องหมุนกี่องศา
จากนั้นแขนกล Dobot MG400 จะใช้หัวดูดหยิบบล็อกไปวางลงช่องทีละชิ้น
ระบบไม่ต้องรู้ชื่อรูปทรงล่วงหน้า เพราะเทียบจากรูปร่างจริงที่กล้องเห็น

**สถานะ: ทำเสร็จแล้ว** หยิบวางได้ครบทุกชิ้นบนแขนจริง

---

## 1. โครงสร้างโฟลเดอร์

```
shapefree-sorter/
├── app/          ← ไฟล์ที่ใช้รันจริงทั้งหมดอยู่ในนี้ (โฟลเดอร์นี้โฟลเดอร์เดียวก็รันได้)
├── images/       ← ภาพผลลัพธ์ ใช้ใส่รายงาน
├── old_test/     ← ไฟล์ทดสอบช่วงแรก ไม่ได้ใช้แล้ว
├── README.md     ← ไฟล์นี้
└── REPORT_OVERVIEW.md  ← ข้อมูลภาพรวมสำหรับทำรายงาน
```

### `app/`: ไฟล์ที่ใช้งาน

| ไฟล์ | หน้าที่ |
|---|---|
| `algo.py` | อัลกอริทึมหลัก: หาวัตถุในภาพ → จับคู่บล็อกกับช่อง (IoU + Hungarian) → หามุมหมุนที่น้อยที่สุด (รันเดี่ยวๆ ได้ จะทดสอบกับฉากจำลอง) |
| `camera_check.py` | ฟังก์ชันจัดการกล้องและภาพ (เปิดกล้อง, threshold, วาดผล) ที่ไฟล์อื่นเรียกใช้ |
| `camera_check_h.py` | ดูภาพกล้องสด ปรับ threshold และตั้งกรอบพื้นที่ทำงาน (ปุ่ม `a`) |
| `calib_utils.py` | แปลงพิกเซล → มม. ของแขน, แปลงมุม, คุยกับแขน MG400 ผ่าน LAN |
| `calibrate.py` | calibrate กล้องกับแขน และอ่านตำแหน่งแขน (`pose`) |
| `pick_place.py` | **โปรแกรมหลัก** ถ่ายภาพ → คิดแผน → สั่งแขนหยิบวาง |
| `calib.json` | ผล calibrate (สูตรแปลงพิกเซล → มม.) |
| `work_area.json` | กรอบพื้นที่ทำงาน (4 มุมกระดาษขาว) |
| `calib_frame.png` | ภาพตอน calibrate (เก็บไว้ดูย้อนหลัง) |

### `images/`: ภาพผลลัพธ์
`demo_step1.png`, `demo_unseen.png` (ผลจากฉากจำลอง), `shape_success.png` (ผลจริง)

### `old_test/`: ไม่ได้ใช้แล้ว

| ไฟล์ | เหตุผล |
|---|---|
| `dobot_api.py`, `api_test.py` | ใช้ทดสอบการเชื่อมต่อแขนช่วงแรก ตอนนี้ `app/calib_utils.py` คุยกับแขนเองแล้ว |
| `frames/*.png` | ภาพที่ถ่ายเก็บไว้ระหว่างทดสอบกล้อง |
| `PROGRESS_old.md` | บันทึกความคืบหน้าช่วงกลางโปรเจกต์ (บางข้อมูลเก่าแล้ว) |

## 3. ติดตั้ง

```
py -3.12 -m pip install opencv-python numpy scipy
```

ทุกคำสั่งข้างล่างรันจากโฟลเดอร์โปรเจกต์ (`shapefree-sorter`)
หรือจะ `cd app` แล้วรันโดยไม่ต้องพิมพ์ `app/` นำหน้าก็ได้ (เช่น `py -3.12 pick_place.py --run`)
ถ้าภาษาไทยในเทอร์มินัลขึ้น `UnicodeEncodeError` ให้พิมพ์ `$env:PYTHONIOENCODING="utf-8"` ก่อน

## 4. อุปกรณ์

- กล้อง Logitech c922 = กล้องเบอร์ 1 ความละเอียด 1280x720 มองลงมาที่โต๊ะ
- แขน Dobot MG400 IP `192.168.1.6` (ตั้ง IP คอมเป็น `192.168.1.10`, subnet `255.255.255.0`)
- หัวดูดลมต่อที่ DO 1
- วางบล็อกและกระดานบนกระดาษขาว

## 5. ขั้นตอนใช้งาน

### ขั้น 0: ทดสอบอัลกอริทึม (ไม่ต้องใช้กล้องหรือแขน)
```
py -3.12 app/algo.py
```
จะทดสอบกับฉากสุ่ม แล้วพิมพ์ % จับคู่ถูกและความคลาดเคลื่อนของมุม และเซฟภาพ `demo_step1.png`, `demo_unseen.png` ไว้ในโฟลเดอร์ที่รันคำสั่ง

### ขั้น 1: ตั้งกรอบพื้นที่ทำงาน (ทำครั้งเดียว หรือเมื่อย้ายกระดาษ)
```
py -3.12 app/camera_check_h.py
```
กด `a` แล้วคลิก 4 มุมของกระดาษขาว จะเซฟลง `app/work_area.json` ให้เอง กด `q` ออก

### ขั้น 2: Calibrate (ทำครั้งเดียว ทำใหม่เมื่อกล้องหรือฐานแขนขยับ)
```
py -3.12 app/calibrate.py calibrate
```
1. ติดสติกเกอร์บนโต๊ะ 5-7 จุด กระจายทั่วพื้นที่ทำงาน
2. กด space หยุดภาพ คลิกสติกเกอร์ตามลำดับ แล้วกด `s`
3. ลากปลายหัวดูดไปแตะสติกเกอร์ทีละจุด กด Enter ทุกจุด
4. ดูค่า error ถ้าเกิน 3 มม. ควรทำใหม่

เช็กผล: `py -3.12 app/calibrate.py check --move` คลิกในภาพแล้วกด `g` แขนจะไปลอยเหนือจุดที่คลิก

### ขั้น 3: ซ้อม (แขนไม่ขยับ)
```
py -3.12 app/pick_place.py
```
กด `m` ระบบจะวาดแผนบนภาพ (คู่บล็อก-ช่อง มุมหมุน และลำดับหยิบ) และพิมพ์พิกัดออกมา

### ขั้น 4: หยิบวางจริง
```
py -3.12 app/pick_place.py --run
```
กด `m` ดูแผน แล้วกด `g` แขนจะหยิบวางจนครบทุกชิ้น

| ปุ่ม | ทำอะไร |
|---|---|
| `m` | ถ่ายภาพและคิดแผน |
| `g` | เริ่มหยิบวาง (ก่อนหยิบแต่ละชิ้นจะถ่ายภาพใหม่ทุกครั้ง) |
| `c` | ล้างแผน |
| `q` | ออก |

ตัวเลือกเพิ่มเติม
- `--no-grip` แขนเคลื่อนตามแผนแต่ไม่เปิดหัวดูด (ใช้ทดสอบท่าทาง)
- `--thresh 78 --blur 4` ค่าแยกวัตถุออกจากพื้น (ค่าเริ่มต้น) ถ้าแสงเปลี่ยน ให้ปรับใน `camera_check_h.py` ก่อน
- `--exposure -6` ล็อกความสว่างกล้อง

## 6. ค่าที่ตั้งไว้ (หัวไฟล์ `app/pick_place.py`)

| ค่า | ความหมาย | ค่าปัจจุบัน |
|---|---|---|
| `PICK_Z` | ความสูงตอนดูดบล็อก (มม.) | -143.0 |
| `PLACE_Z` | ความสูงตอนปล่อยลงช่อง (มม.) | -132.2 |
| `SAFE_Z` | ความสูงตอนเคลื่อนข้ามไปมา (มม.) | 6.1 |
| `CLEAR_POS` | จุดที่แขนไปรอ ไม่บังกล้อง | (316.5, -168.6, 24.6, -86.3) |
| `PICK_R` | มุมหัวดูดตอนหยิบ | -70.0 |
| `SPEED` | ความเร็วแขน (%) | 20 |
| `COLLISION_LEVEL` | ความไวตรวจการชน (1-5) | 3 |
| `RETRY_STEP`, `MAX_RETRY` | ถ้าดูดไม่ติด รอบถัดไปจะลงต่ำลงทีละ 1 มม. ได้สูงสุด 6 ครั้ง | 1.0, 6 |

## 7. ข้อควรระวัง

- **ห้ามขยับกล้องหรือฐานแขน** หลัง calibrate ถ้าขยับต้อง calibrate ใหม่
- บล็อก กระดาน และกระดาษ ย้ายได้ แต่ต้องอยู่ในกรอบพื้นที่ทำงาน
- วางบล็อกห่างจากกระดานเล็กน้อย ถ้าติดกันจะถูกนับรวมเป็นกระดาน
- ถ้าแขนชน ระบบจะหยุดเองและปิดหัวดูด ให้เอาของที่ชนออกแล้วรันใหม่
