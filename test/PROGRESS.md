## อุปกรณ์และการตั้งค่า

**กล้อง**
- Logitech c922 = **กล้องเบอร์ 1** (กล้องโน้ตบุ๊ก = เบอร์ 0)
- ตั้ง**เอียง** ไม่ได้มองตรงลงมา
- วางบล็อกไว้**ด้านบน**ของภาพ กระดานไว้**ด้านล่าง** บนกระดาษขาว
- ค่าที่ใช้ได้: threshold **142**, blur **4**, split **35–38**

**แขน MG400**
- IP แขน `192.168.1.6`
- IP คอม (Ethernet ตั้งเอง) `192.168.1.10`, subnet `255.255.255.0`
- หัวจับเป็น**หัวดูดลม**

**ถ้าแขนขึ้น error (RobotMode = 9)** ให้รันคำสั่งนี้ แขนจะไม่ขยับ:
```
cd test
python -c "from calib_utils import Robot; r=Robot(); r.d('ClearError()'); r.d('RobotMode()'); r.d('GetErrorID()')"
cd ..
```
ผลต้องเป็น `RobotMode {5}` ถึงจะพร้อมใช้งาน

## ขั้นตอนต่อไป

**1. ทดสอบหัวดูด** (แขนไม่ขยับ เอาบล็อกไปแนบใต้หัวดูดค้างไว้)
```
cd test
python -c "from calib_utils import Robot; import time; r=Robot(); r.d('DO(1,1)'); time.sleep(3); r.d('DO(1,0)')"
cd ..
```
ต้องดูดติด 3 วินาทีแล้วปล่อย ถ้าไม่ดูด ลองช่อง DO 2 หรือสลับ GRIP_ON

**2. ให้แขนเคลื่อนตามแผน แต่ยังไม่ดูด** ⚠️ มืออยู่ที่ปุ่มหยุดฉุกเฉิน
```
python test/pick_place.py --run --no-grip --split 35
```
กด `m` ดูแผน แล้วกด `g` ลงมือ

**3. หยิบวางจริง**
```
python test/pick_place.py --run --split 35
```

**ซ้อมโดยแขนไม่ขยับ** (ตัดคำว่า `--run` ออก)
```
python test/pick_place.py --split 35
```

## กฎสำคัญ

| ขยับได้ ✅ | ห้ามขยับ ❌ (ถ้าขยับต้อง calibrate ใหม่) |
|---|---|
| บล็อก (ย้าย/หมุนได้) | **กล้อง** |
| กระดาน | **ฐานแขน** |
| กระดาษขาว (แต่ควรแปะเทปมุมไว้) | |
| สติกเกอร์ (ใช้แค่ตอน calibrate) | |

- บล็อกต้องอยู่**เหนือเส้นฟ้า** กระดานอยู่**ใต้เส้นฟ้า** ทั้งหมดอยู่**ในกรอบม่วง**
- ต้องวางอยู่ในบริเวณที่ calibrate ไว้ ถ้าอยู่นอกนั้นโปรแกรมจะข้ามชิ้นนั้นไป

**วิธี calibrate ใหม่**
1. ติดสติกเกอร์ 5–7 จุด ครอบทั้งฝั่งบล็อกและฝั่งกระดาน
2. รัน `python test/calibrate.py calibrate`
3. ขยายหน้าต่างให้ใหญ่ → กด space → คลิก**กลางสติกเกอร์**ให้ครบทุกจุด → กด `s` **ครั้งเดียว**
4. หมุนหัวไว้ที่ r ≈ −70 แล้ว**ไม่หมุนอีก**
5. แตะทีละจุด โดยให้หัวดูด**แตะกระดาษจริง**ทุกจุด แล้วกด Enter
6. error ต้องไม่เกิน 3 มม.

## ปัญหาที่รู้แล้ว / ไอเดียที่ยังไม่ได้ทำ

- **กล้องเอียงทำให้ตอนหยิบบล็อกอาจเบี้ยว**
  บล็อกสูงประมาณ 3 ซม. กล้องมองเฉียงเลยเห็นด้านข้างบล็อกด้วย จุดกลางบล็อกในภาพจึงเลื่อนไป ส่วนรูบนกระดานไม่มีปัญหา
  วิธีแก้ เรียงจากดีที่สุด:
  1. ตั้งกล้องมองตรงลงมา
  2. calibrate รอบที่ 2 ที่ความสูงเท่าผิวบนบล็อก
  3. ใส่ค่าชดเชยตอนหยิบ
- **หาจุดเขียวอัตโนมัติ** (auto-calibrate ทุกครั้งที่กด m) ทำได้ แต่สติกเกอร์ต้องติดกับโต๊ะหรือถาด **ห้ามติดบนกระดาษ** และต้องเห็นอย่างน้อย 4 จุด
- **โหมด `--auto`** ดู → คิด → หยิบจนครบโดยไม่ต้องกดปุ่ม
- **ลำดับการหยิบ** (`order_plan`) ตอนนี้ใช้วิธีหยิบชิ้นที่ใกล้ที่สุดก่อน เป็นงานของคน B ที่ต้องหาวิธีที่ดีกว่าและวิเคราะห์ Big-O
